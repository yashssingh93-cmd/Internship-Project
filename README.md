# Codic Desk - Asset & IT Ticket Portal (Full-Stack)

Internal IT operations portal built during the 6-week Python Developer summer training at Codic Technologies.

- **Frontend:** `static/index.html` (HTML5, Tailwind CSS via CDN, Lucide icons, vanilla JavaScript)
- **Backend:** `app.py` (Python, Flask, SQLite via the built-in `sqlite3` module)
- **Database:** `codic_desk.db` is created automatically on first run and loaded with demo records

## How to run

1. Install Python 3.9 or newer.
2. Open a terminal in this folder and create a virtual environment (optional but recommended):
   ```
   python -m venv venv
   venv\Scripts\activate          (Windows)
   source venv/bin/activate       (macOS / Linux)
   ```
3. Install the dependency: `pip install -r requirements.txt`
4. Start the server: `python app.py`
5. Open http://127.0.0.1:5000 in a browser (internet needed once for the Tailwind and icon CDNs).

To reset the data, stop the server and delete `codic_desk.db`.

## Run the tests

```
python -m unittest test_api -v
```

## REST API

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/assets` | List all assets |
| POST | `/api/assets` | Register an asset (name, tag, category, dept, employee) |
| PATCH | `/api/assets/<id>/toggle` | Switch Assigned / In Storage (employee required to assign) |
| DELETE | `/api/assets/<id>` | Delete an asset |
| GET | `/api/tickets` | List all tickets |
| POST | `/api/tickets` | Raise a ticket (requester, summary, tag, priority) |
| PATCH | `/api/tickets/<TKT-id>` | Change status: Open, In Progress, Resolved |
| GET | `/api/stats` | Summary counts and assets per department |

## Design notes

- All SQL uses parameterized queries (`?` placeholders) to prevent SQL injection.
- Input is validated on the server as well as in the browser (tag pattern, unique tags, valid category, department, priority and status values).
- One SQLite connection is opened per request and closed automatically.
- Ticket numbers start at TKT-1001 and are generated by the database.
- The browser escapes all user text before displaying it.
